One emoji, one dream vacation: 🏝️ — a desert island. Palm, sand and open sea in a single glyph, the faraway escape a stranger can picture before reading a word. The program writes exactly that one emoji (U+1F3DD, 4 bytes UTF-8, no words, no newline) to `/output/entry.txt`, then reads it back and refuses to leave a bad entry behind.

## Run it

```sh
node main.ts
```
